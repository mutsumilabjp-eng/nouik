# 公開前ファクトチェック台帳

確認日: 2026-08-11

## 方針

- 「脳イキ」は医学的な正式名称ではない。
- 論文や公的情報は、一般的な効果保証ではなく、表現を弱めるための確認材料として扱う。
- 根拠が薄い主張は、削除するか「報告されることがある」「可能性がある」「未確立」に弱める。
- F03(科学的根拠と論文の現在地)は、出典確認が揃うまで公開しない。

## 主張台帳

| 対象 | 公開前判定 | 対応 |
|---|---|---|
| イメージや音声で快感に近い反応を感じたと語られることがある | 限定的に可 | F01で「身体反応(骨盤底収縮など)」の断定を削除し、仕組み・再現性は未確立と明記 |
| 「身体的な危険性は限定的」「外傷や感染リスクは小さい」 | 不可 | F04/F09から削除し、安全断定を避ける表現へ変更 |
| 注意・集中のメカニズムとして知られている | 要弱化 | F06で「重ねて考えられる場合がある」に変更 |
| 「典型的」「よく見られる」 | 要弱化 | F06/F08で「語るパターンの1つ」に変更 |
| 無意識の自己制御 | 要弱化 | F08で「ブレーキ感」に変更 |
| 評価的な意識が心地よさを妨げる | 要弱化 | F11で「注意が向きにくくなる可能性」に変更 |
| 呼吸を整える | 無料手順に見えやすい | F07で「一度中断して落ち着ける時間」に変更 |
